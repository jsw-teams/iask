# Deployment and free allowances

Verified 2026-10-04. Rank only platforms that satisfy iask's persistent-state and locking requirements. Static hosting alone cannot run its sign-in and comments backend.

| Priority | Platform | Free allowance | Deployment and limits |
| --- | --- | --- | --- |
| 1 | Cloudflare Workers + SQLite Durable Objects | Worker and DO requests each have a separate 100,000/day limit; DO duration 13,000 GB-s/day; SQLite 5 million rows read/day, 100,000 written/day, 5 GB total storage | Native persistent storage, no external database account. Each SQLite object has its own 1 GB Free limit. Static assets are free and unlimited. Exceeding a Free meter fails that operation until reset; this is not a guarantee of 100,000 visitor sessions. [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/), [DO pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/), [object limits](https://developers.cloudflare.com/durable-objects/platform/limits/). |
| 2 | Netlify Functions + Netlify Database | Free has 300 shared credits/month; production deploy 15 credits, DB compute 10 per CU-hour, functions 10 per GB-hour, web/DB bandwidth 20 per GB | Database is provisioned from `@netlify/database`, with schema applied from committed migrations. No separate database registration or manually entered URL. Only 30 database CU-hours would fit if every credit were spent on database compute, before all other meters; inactivity before sleep counts. Exhaustion pauses the site until monthly reset. [Database setup](https://docs.netlify.com/build/data-and-storage/netlify-database/getting-started/), [DB billing](https://docs.netlify.com/build/data-and-storage/netlify-database/billing-and-usage/), [shared credits](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/credit-based-pricing-plans/). |
| Existing database only | Vercel | Hobby includes 1 million function invocations/month, 4 CPU-hours and 360 GB-hours provisioned memory | Personal non-commercial use; PostgreSQL must be supplied separately. Its function allowance does not include the external database, so this is not a recommended one-click option for this project. [Hobby limits](https://vercel.com/docs/plans/hobby). |

Cloudflare is the practical first choice for a free production iask instance. Netlify is a genuine integrated database alternative, but its shared credits can run out well before a nominal function request limit. Netlify's published storage page still mentions an expired promotional period without a confirmed current storage rate; verify current dashboard billing before enabling paid usage. Do not count that promotion as continuing free storage.

Vercel's existing adapter remains available for operators with a verified-TLS direct PostgreSQL connection or a session-mode pooler. EdgeOne and ESA remain compatible hosts for the website frontend; their key-value storage is not a replacement for the coordinator's serialized persistent operations. No unverified backend adapter is advertised.

The Netlify adapter is under `backend/netlify/`, reuses shared PostgreSQL persistence, and uses the documented Neon direct endpoint to avoid transaction-pooler session-lock loss. Hosted SQL schema changes come only from `netlify/database/migrations/`. Static files bypass Functions; only explicit service paths invoke them. [Netlify function routes](https://docs.netlify.com/build/functions/configuration/), [connection API](https://docs.netlify.com/build/data-and-storage/netlify-database/api/), [Neon pooling](https://neon.com/docs/connect/connection-pooling).

Repository configuration and adapter tests do not establish that a hosted Netlify database has been exercised. The current JS.GRIPE production instance continues to use Cloudflare.
