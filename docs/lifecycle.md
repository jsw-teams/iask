# 数据与更新生命周期

版本使用年月和当月第几次更新，例如 `202610.4`。发布版本不是数据命名空间；升级、改名或更换 App 私钥不得重置正式评论。

目前正式评论使用格式 1。签名、原始用户 ID、线程标识和来源配置继续保留。更名只改变公开名称和新的部署配置名称，不改变既有存储标记、签名域、媒体路径或 Durable Object 名称。已有 `REPORELAY_*` 配置作为部署别名继续读取，便于保留凭据；新部署使用 `COMMENTNEST_*`，同一字段的新配置优先。

旧测试格式停止支持，旧 Issues 保留隔离，不导入、不删除、不以其他人的身份重新发表评论。

后续先保持正式格式可读。确实无法继续支持时，发布迁移说明、校验与回滚步骤，完成前保留原始数据。无法保留原作者身份或验证失败的数据不能重新发表；未迁移数据保持隔离。

改域名、改仓库或新建 Worker/DO 命名空间属于部署迁移。先备份并设计签名与媒体 URL 的迁移，不要只改配置后期待原数据自动出现。GitHub App 归属和 OAuth 设置不随源代码仓库更名自动转移。
